# Talep Isı Haritası

Bu ekran `GET /project-sales/demand-heatmap` sözleşmesini kullanır.

- Konum kaynağı: EPH Global Konum Modülü (`frontend/src/components/stok/locationData.ts`)
- Veri kaynağı: anonim/toplulaştırılmış Talep Merkezi kayıtları
- Özel CRM verisi kullanılmaz
- Kimlik, telefon, e-posta, başlık ve açıklama gösterilmez
- Dönem: 7/14/30/60/90 gün
- Filtre: il/şehir ve ilçe
- Mahalle/hassas istatistikler backend mahremiyet eşiğine tabidir
